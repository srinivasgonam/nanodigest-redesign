# Nano Digest Redesign — Design System

## Purpose
A modern editorial interface for Nano Digest, focused on nanotechnology, research, materials, medicine, energy, and scientific innovation.

## Visual direction
- Editorial
- Scientific
- Minimal
- Professional
- Calm
- High readability

## Colors
- Background: #FAF6F6
- Primary (brand): #C91212
- Primary dark (headings): #8D0F10
- Text: #2B2223
- Muted: #7A6F70
- Accent (blush): #F6C9C9
- Border: #ECDEDE

Brand red (#C91212) matches the production site's accent colour. WhatsApp greens
(#49D17F/#0F8A5F) and YouTube reds (#D90B00/#FF5147) are retained for their
respective channel icons; success/error states keep their semantic colours.

## Typography
- DM Sans: body/UI
- Manrope: display headings and wordmark

## Spacing
4, 8, 12, 16, 24, 32, 48, 64, 80px

## Implementation
- React + Vite
- Plain CSS
- No external design-platform runtime
- Frontend-only interactions
