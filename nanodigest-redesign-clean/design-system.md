# Nano Digest Redesign — Design System

## Purpose
A modern editorial interface for Nano Digest, focused on nanotechnology, research, materials, medicine, energy, and scientific innovation.

## Visual direction
- Editorial
- Scientific
- Minimal
- Professional
- Calm
- High readability

## Colors
- Background: #F6F8F5
- Primary: #173D33
- Text: #203C36
- Muted: #718079
- Accent: #D9EE93
- Border: #DCE3DB

## Typography
- DM Sans: body/UI
- Manrope: display headings and wordmark

## Spacing
4, 8, 12, 16, 24, 32, 48, 64, 80px

## Implementation
- React + Vite
- Plain CSS
- No external design-platform runtime
- Frontend-only interactions
